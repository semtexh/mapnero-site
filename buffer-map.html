25-SECOND GIS EXAMPLE

Create a 50 m buffer around a point.

Select a point on your map and set a distance. Buffer creates a separate polygon while keeping the original point unchanged.

Follow the steps ↓

From a point to a separate polygon.

  1. Select your source point. Tap it on the map or select it in Layers. Open Buffer from the detail card; scroll the action row if necessary.
  2. Enter 50 and choose metres. Check the unit before creating the result. You can enter a name or keep the automatic name.
  3. Preview and choose the appearance. Preview shows the sources and polygons that can be processed. It does not save a result. Set the fill colour and opacity.
  4. Choose Create Buffer. The result is added to the separate Derived Buffers layer. Close the feature card to inspect it on the map.
  5. Check the result. Confirm the source, distance and unit you used. The original point remains unchanged. Updating a saved buffer's distance requires its original source.

What does the 50 m distance mean?

This example uses a point and a 50 m buffer distance around it, rather than a 50 m diameter. Choosing feet instead of metres changes the distance.

The polygon is a geometric area. It does not improve the accuracy of the original coordinates or certify a safety boundary. Check your source data and use the requirements appropriate to your work.

Buffer questions

Is this the circle drawing tool?

No. Buffer derives a polygon from a source feature. For a distance around a location, select a point and use Buffer. The circle drawing tool is a separate workflow.

Can I use a line, track or polygon?

The full Buffer guide also covers these source types. Their buffer areas follow the source geometry, so they will not look like the point example in this video.

Can I change the appearance later?

Select the saved buffer to change its colour or opacity. Changing the distance needs the original source feature.
