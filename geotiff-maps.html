CHECK THE SOURCE FILE

A TIFF image needs geographic information.

A GeoTIFF carries information about its coordinates and position. Renaming an ordinary image to .tif does not add that information. Keep your original file, check its coordinate reference system and compare known locations after import.

Large rasters and different compression methods can affect whether a file opens. Start with a small sample of your actual map before preparing a large field project.

Choose your platform.

iPhone and iPad

  1. Save the GeoTIFF where you can access it in Files.
  2. Open Import Map and choose Select from Files.
  3. Open the imported map, compare several known positions and use Locate to check your location.

Android

GeoTIFF handling is more limited on Android. Support depends on the file. Test your own GeoTIFF on the target device before a trip.

If it cannot be opened, use a supported map format such as a georeferenced PDF and check its alignment again. Converting a file does not correct inaccurate source coordinates.

Test the map offline.

Finish importing the map while you can access the source file. Turn on Airplane Mode, reopen the map and inspect the area and level of detail you need. Download and test any basemap region separately.

An imported map and a downloaded basemap are separate resources. Confirm both before leaving coverage.

GeoTIFF questions

Will every GeoTIFF work?

No. File size, compression, georeferencing and platform support can affect the result. Test a representative file on your actual device.

Does importing improve accuracy?

No. Source-map accuracy and phone GPS accuracy still matter. Compare independent known landmarks, not only the points used to align a map.

Is GeoTIFF export the same as import?

No. They are separate operations. The current mobile export guide lists GeoTIFF export under Core or higher. Check the guide for your platform before choosing a plan.
