FORESTRY FIELD GUIDE

Record a plot.
Find the result again.

Record fixed-area and prism plot visits offline, check the results, and save an HTML report you can reopen in MapNero.

Record a plot visit → Check stems/ha or basal area → Save and reopen the HTML report. Forestry analysis requires Pro access.

Watch the walkthrough on YouTubeDownload MapNero

About three minutes, with English narration and captions. The footage uses a real iPhone running the 2.2.8 test build, fictional maps and sample records. The voice is synthetic. Controls can differ on Android.

MapNero 2.2.8 is available on iPhone/iPad and Android. Importing unlimited personal maps remains free. Check your installed version and plan before starting a working survey.

Start with one practice plot

  1. Choose Forestry mode. In Settings, open Usage Mode and select Forestry.
  2. Choose where records belong. Open the green tree button in the library and check Working layer. Use a separate practice layer while learning.
  3. Open a survey. Choose New survey record, select your example plot and open the built-in form.
  4. Enter and check the measurements. For the fixed-area example, enter a plot area of 50 m² and 6 measured stems. Check the result before saving.

Two examples, two different measures

Fixed area: 1,200 stems per hectare

Six stems in 50 m² gives 6 ÷ 50 × 10,000 = 1,200 stems/ha. This is stem density for the example plot, not a complete inventory estimate.

Prism: 28 square metres per hectare

In a separate prism visit, BAF 4 × 7 IN trees = 28 m²/ha of basal area. Use the correct BAF and units for your instrument and measurement method.

Stems/ha counts stems per area. Basal area in m²/ha measures cross-sectional tree area per land area. Do not compare these numbers as if they used the same unit.

Save, reopen and find the report

  1. Save the visit. Return to the same plot pin and open Linked survey records to check the saved entry.
  2. Review a calculation. Open Calculations from the green tree menu. Check the selected plot and saved visit so the result uses the intended records.
  3. Create a report. Open Reports, choose the plot survey summary and review its scope. The walkthrough saves an HTML report using Save report in MapNero.
  4. Find it later. Open Saved reports, select the saved entry and choose Open report. Check the plot, visit and figures again.

The video demonstrates saving and reopening an HTML report. It does not demonstrate every export format or an Android export workflow.

Before fieldwork

Try the workflow with a copy of a representative map and practice records. Reopen the map offline, check several known locations and verify the saved measurements and report. Keep your original files and follow your survey protocol when choosing plot areas, sampling methods and IN trees.
