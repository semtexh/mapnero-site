Read the steps ↓

Measure a distance in three steps.

  1. Open the tool. On iPhone, open More → Measure.
  2. Place points. Choose positions on the map to define the measurement.
  3. Read the live result. Check the line label and distance panel as you place points.

Read the result in context.

The 371-metre value belongs to this example. A map measurement is not an independently surveyed ground distance. Check the source map and the positions you choose before using the result for field decisions.
