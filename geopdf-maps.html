BEFORE YOU START

A PDF needs a geographic position.

A GeoPDF includes information that places the map in the real world. A regular PDF may only contain a picture of a map. Opening that file does not establish where your GPS position belongs on it.

Use a map with valid georeferencing and check a known location after import. If your position appears outside the map, compare it with the Base Map and check the source file.

CHOOSE YOUR DEVICE

From a map file to an open map.

iPhone and iPad

  1. Open Import Map from the map or Library.
  2. Choose Select from Files and select your PDF or GeoPDF.
  3. Open the imported map. Tap Locate and check the map against a known position.

You can also open a supported file from the Files app with MapNero. Multi-page PDFs require Pro on Apple platforms.

Open the Apple import guide →

Android

  1. Open Add Map, then choose Import PDF Map.
  2. Select your map file. Review any import information or warnings shown.
  3. Open the map and check its position before field use.

You can also select a supported file in Downloads or Files and use Open with MapNero.

PREPARE BEFORE LEAVING COVERAGE

Check your map without a network.

Finish importing your file while you have access to it. Turn on Airplane Mode, reopen the map and check the area and detail you need. If you also need a basemap region, download and test that region separately before leaving coverage.

Questions about PDF maps

Why is the map blank?

Check that the file finished importing and that the view is within its geographic bounds. A missing basemap download is a separate issue from a local PDF import.

Can I use a photo instead?

The Apple guide includes manual image referencing with Core or higher. It requires at least three well-spaced, non-collinear control points with known coordinates. Read the photo referencing guide before starting.

What should I do with an older misaligned PDF import?

Compare the map against a known position first and retain the original file and your saved records. The import guides describe reimporting an older PDF so the current georeference parser runs. Check those steps before replacing an imported copy.
