## Download MapNero and try a map

MapNero is free to download on iPhone, iPad, Android and Mac. Use a small example to check map position and offline access before fieldwork.

- [Download on the App Store](https://apps.apple.com/app/apple-store/id6758651027?pt=128311453&ct=github_readme&mt=8)
- [Get it on Google Play](https://play.google.com/store/apps/details?id=com.thenerolabs.mapnero&utm_source=github&utm_campaign=github_readme)
- [Get the free GeoPDF practice map and import steps](https://www.mapnero.com/geopdf-maps.html?mn_campaign=github_readme#practice-map)

This repository hosts the MapNero public website, guides, and community feature spotlights. Explore the guides for current feature availability and platform or plan requirements.
