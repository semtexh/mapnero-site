Compare several known landmarks across the map. Then turn off the network and reopen it to check the area and detail you need. Download any basemap region separately.

Before you decide

Is unlimited map importing really in Free?

Yes. MapNero Free has no map-count cap for your own supported map imports. This does not make every file format, paid tool or basemap download unlimited. Multi-page PDF import requires Pro on Apple platforms.

Do I need to subscribe to try my map?

You can start with Free and a supported map. Check the platform-specific guide before choosing a paid plan for additional tools.

What if I have no map file to test?

Download our free fictional practice GeoPDF to learn the import steps. It is not real terrain and must not be used for navigation. For a real field test, use a map of an area you know.

Will every map, photo and attribute transfer unchanged?

Do not assume that. Retain the source files and test a representative sample on your actual device. If something differs, contact MapNero support with the file type, app version and a non-sensitive example.
